LUMENFALL is a top-down arena survival game: keep the last lantern lit through 10 waves of gloom, choose a blessing between waves, and slay the Gloom Warden. WASD to move, mouse to aim, hold click to fire embers, Space to dash.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
